MAC

Open the DMG and run WADAHEX Installer.pkg. It's signed and notarized by Apple.

WINDOWS

Run WADAHEX_win_setup.exe. If SmartScreen warns you, click More info > Run anyway.

VST3 goes to C:\Program Files\Common Files\VST3.
